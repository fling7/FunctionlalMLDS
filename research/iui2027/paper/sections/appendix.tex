\section{Evaluation and Artifact Checklist}

The anonymous supplement will contain the following materials:

\begin{itemize}
  \item immutable scene and agent inputs;
  \item held-out interaction items and expected outcomes;
  \item direct-wiring and model-grounded condition definitions;
  \item change-task patches and fault-mutation catalog;
  \item raw machine-readable outcomes;
  \item scripts that regenerate tables and figures; and
  \item environment and content-hash manifests.
\end{itemize}

Any repository URL, file metadata, screenshot, or video included for review will
be checked for identifying information.
