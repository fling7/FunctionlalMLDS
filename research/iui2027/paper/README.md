# IUI 2027 paper

This directory contains the anonymous ACM IUI 2027 main-paper submission.

## Required review format

The document must use:

```latex
\documentclass[manuscript,review,anonymous]{acmart}
```

The target is at most 8,000 words, excluding references, captions, and
appendices. Results marked with `\resultpending{...}` are deliberately
unresolved and must never remain in a reviewer submission.

The current local build uses `acmart` 2.19 (2026-06-27), installed from the
MiKTeX package repository and recorded by the LaTeX build log. It builds a
tagged PDF/UA-2 manuscript with LuaLaTeX and a pinned LaTeX tagging stack.

## Build on Windows

MiKTeX and Git are required. Prepare the exact tagged-PDF support tree once,
then build:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\prepare_tagged_tex.ps1
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

The PDF is written to `build/main.pdf`. Build products are ignored by Git.
`iui2027-anonymous-submission.pdf` is the tracked, reviewer-ready snapshot
copied from that build after all local gates pass; update it after every paper
revision.
The preparation script checks out LaTeX tag `latex-lab-2025-11-01a`, verifies
commit `c5afb829ef326a0469435da85636c973cc258b3f`, and extracts its
`latex-lab` files below the ignored `.latex-toolchain/` directory. `build.ps1`
refuses a different revision.

For the final accessibility gate, install veraPDF 1.30.2 and run:

```powershell
$env:VERAPDF_BAT = "C:\path\to\verapdf.bat"
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -ValidatePdfUa
```

The build fails unless veraPDF reports `PASS` for PDF/UA-2. The manuscript also
contains explicit alternative text for every TikZ figure.

## Submission checks

Before any external upload:

1. no pending result markers;
2. no author names, affiliations, acknowledgements, identifying URLs, or local paths;
3. all numbers generated by the committed evaluation pipeline;
4. all references resolve;
5. PDF and supplements contain no identifying metadata;
6. file size below 10 MB and the complete scientific argument, including the
   Conclusion, within the first 15 pages analyzed by paperreview.ai. The
   service accepts a longer IUI manuscript but ignores later pages.

During development, run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
python .\check_submission.py --allow-pending
```

Before any external upload, omit `--allow-pending`. The strict check fails if a
result marker, obvious identity leak, undefined citation, overfull box, format
deviation, or reviewer upload-limit violation remains.
