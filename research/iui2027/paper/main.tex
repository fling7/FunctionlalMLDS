\begin{abstract}
People in interactive three-dimensional environments increasingly communicate
with embodied agents about objects that they can see, approach, or point to.
Implementing such an interface requires developers to keep spatial entities,
agent responsibilities, knowledge, prompts, runtime actions, and observable
outcomes consistent. These relationships are commonly distributed across a
scene editor and an agent backend, which makes interaction failures difficult
to explain and changes difficult to validate. We present \systemname{}, a
model-grounded authoring and runtime layer for embodied multi-agent interfaces
implemented in a Unity desktop prototype with a WebXR deployment path and a
conversational-agent backend. The layer makes
the path from a user-facing scenario and spatial target to an agent capability,
runtime action, and validation assertion explicit and executable. We evaluate
the approach against direct artifact wiring in three spatial environments using
held-out reference and routing tasks, controlled authoring changes, and
systematic fault injection. \resultpending{Insert the principal comparative
results after the clean evaluation run.} The contribution is a technical and
interaction-oriented account of how explicit model grounding can make spatial
agent behavior controllable, traceable, and reproducibly testable; it does not
claim improvements in subjective user experience without a human-participant
study.
\end{abstract}
